SpringBoot

Tuesday, October 6, 2026

按照学习顺序来组织一下SpringBoot的一些八股，同时也方便以后复习的时候线性阅读，减少跳跃式阅读。

Q：SpringBoot的优点是什么？
A：

starter提供相关组件需要的依赖组合、autoConfigure自动配置需要的bean、内嵌web服务器不需要手动配置tomcat，SpringBoot结合这些实现“convention over configuration”，没有用户显示配置时优先默认约定。

举个例子来说：starter web 依赖 spring-boot-webmvc和spring-boot-autoconfigure，WebMvcAutoConfiguration的ConditionalOnClass条件包含webmvc的DispatcherServlet和WebMvcConfigurer。引入starter web后，autoconfigure中的配置才会启动。

Q：SpringBoot的自动配置原理？
A：

@SpringBootApplication->@EnableAutoConfgiguration->@Import{AutoConfigurationImportSelector.class}导入自动配置类->进行去重排除组织->处理自动配置类中的bean并添加BeanDefinition->Spring IOC创建Bean。

1、@SpringBootApplication注解中的@EnableAutoConfiguration开启自动配置

2、通过@Import导入 AutoConfiguarationImportSelector 导入选择器，首先从AC配置元数据文件中获取所有的自动配置类全类名。

3、去重，排除，根据before、after等注解安排AutoConfiguration中的顺序。

4、解析自动配置类中的bean，按照条件进行排除、筛选，然后添加BeanDefinition

5、SpringIOC容器再根据这些beanDefinition创建bean。

@EnableAutoConfiguration 上的 @Import(AutoConfigurationImportSelector.class)，把 autoconfigure 包下约 146 个 xxxAutoConfiguration 自动配置类批量导入进来。

其中AC配置原数据文件：原来springboot2.7之前在resources/META-INF/spring.factories中配置，现在springboot2.7之后在resources/META-INF/spring/org...AutoConfiguration.imports中一行写一个自动配置名。

Q：SpringBoot如何添加一个starter？
A：

基于自动配置添加一个starter的流程不复杂，总体上就是：1、添加配置类。2、在AutoConfiguration中注入配置类，并根据配置类和当前已经注入的类设置Conditional来添加bean。3、在metainf下面的AutoConfigure自动配置类元信息文件中添加自动配置类的全类名。使用时：1、引入starter。2、在application.yml中添加配置。

具体来说：配置类上面添加@ConfigurationProperties注解，自动配置类上面添加@EnableConfigurationProperties来注入配置类到ioc容器中，添加@AutoConfiguration表示配置类，其他步骤已经说的比较详细了，这里不再重复。

Q：SpringBoot的启动流程？
A：

SpringApplication启动后，处理配置环境，准备ApplicationContext，扫描所有组件以及自动配置类中的bean并加载到ioc容器，启动内嵌服务器，然后执行ApplicationRunner和CommandLineRunner的任务，最后SpringBootApplication准备完成

  • SpringApplication.run(…)
  • 准备Enviroment：命令行参数、读取application.yml、加载profiles、形成配置环境
  • 创建ApplicationContext
  • refresh：进行组件扫描、自动配置类扫描处理出BeanDefinition，然后实例化初始化非懒加载单例Bean。内嵌服务器也在这个过程中创建并初始化。
  • 执行实现ApplicationRunner和CommandLineRunnner的任务。
  • SpringBootApplication准备就绪。
Q：@Value和@ConfigurationProperties有什么区别？
A：
一个是绑定单个配置到字段上；一个是绑定一组配置到对象上。
Q：配置环境的优先级？命令行参数、JVM系统参数、环境变量、配置文件参数？
A：

优先级为：命令行参数 > JVM系统参数 > 环境变量 > 配置文件参数。

具体的

# 命令行参数
java -jar app.jar --server.port=8083

# JVM System property JVM系统参数
java -Dserver.port=8083 -jar app.jar

# 环境变量参数
SERVER_PORT=8083 java -jar app.jar

配置文件参数内部也有优先级：

- application-prod.yml # 包外profile
- application.yml # 包外普通配置
- app.jar
    - application-prod.yml # 包内profile
    - application.yml # 包内普通配置
Q：SpringBoot的Filter和Interceptor说一下？
A：
Filter是Servlet层的，一般在SpringMVC的DispatcherServlet前后调用，可以通过注册FilterRegistrationBean来实现filter的注入，创建时指定filter、name和优先级。Interceptor是SpringMVC中的，一般拦截handler的执行，包括controller方法和静态资源的拦截处理。
Q：SpringBoot如何开启事务？
A：
在引入starter-jdbc或者starter-jpa，并且正确配置数据源的情况下，springboot自动启用事务管理，无需手动@EnableTranscationalManagement开启。
