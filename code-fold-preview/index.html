单行代码

只有 1 行也会折叠，试试点击“展开代码”：

短代码

下面是 5 行 Python，展开后可复制完整内容：

def greet(name):
    message = f"Hello, {name}!"
    return message

print(greet("Stack"))

较长的代码

下面是 20 行 JavaScript，用来体验长代码的展开与收起：

const articles = [
    { title: "学习笔记", category: "技术" },
    { title: "生活记录", category: "日常" },
    { title: "项目实践", category: "技术" },
];

function groupByCategory(items) {
    const groups = new Map();
    for (const item of items) {
        const list = groups.get(item.category) ?? [];
        list.push(item.title);
        groups.set(item.category, list);
    }
    return groups;
}

const groups = groupByCategory(articles);
for (const [category, titles] of groups) {
    console.log(category, titles.join("、"));
}

如何使用

在文章开头的 YAML front matter 中加入 codeFoldLine: 1 即可。想使用常规长代码折叠，改为设置 codeFold: true；想让整篇代码始终展开，删除折叠参数或设置 codeFold: false。
